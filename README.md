# Hermes Employees landing page

An original, animated monochrome landing page for a service that builds 24/7 AI employees on top of [Hermes Agent](https://github.com/NousResearch/hermes-agent).

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Stack

- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- Canvas signal-field animation
- Reduced-motion accessibility support
- GitHub Pages deployment

## Booking CTA

The current CTA opens a structured GitHub Issue form so booking requests are captured. Replace the CTA URL in `index.html` with a Cal.com or Calendly URL when available.

## Brand note

This is an independent implementation studio concept built on Hermes Agent. It is not an official Nous Research website. The Hermes illustration and favicon are sourced from the MIT-licensed `NousResearch/hermes-agent` repository.
